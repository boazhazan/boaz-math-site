# Boaz Hazan — private mathematics lessons

Buildless Hebrew, RTL website. Static files are in `dist/`.

- `index.html`: personal introduction, teaching background, lesson prices, FAQ and a WhatsApp enquiry builder.
- `practice.html`: three sample mathematics exercises with hints and solutions.
- `feedback.html`: feedback questionnaire for parents, students and professionals.

The enquiry and feedback forms do not send messages automatically. They prepare WhatsApp messages that visitors review and send themselves. No responses are stored by this static website. Questionnaire answers are private feedback by default in use: no publication permission is preselected, and publication requires an explicit choice. Only the separately entered approved quote and selected attribution can be published. Nothing is automatically added to the website.

Before publishing any recommendation, retain the original permission and exact approved quote. Do not publish other questionnaire answers. Obtain fresh approval for edited quotes. Honour withdrawal requests. Do not import recommendations from the old website without confirming authenticity and publication permission.

The live lesson-booking integration is pending inspection of the parent booking flow; the website currently uses WhatsApp enquiries. Do not point visitors to the internal family/calendar management screen.

The legacy GitHub Pages website remains untouched by this project. A ZIP of its original checked-out revision is stored separately in `../archive/original-teaching-site.zip`.

## Local preview

Serve `dist/` with a static HTTP server. No dependency installation or build step is needed.

## Verified in the browser

- Private feedback includes a clear denial of publication permission.
- Explicit publication consent includes only the designated quote and selected attribution as publishable content.
- Switching from publication consent back to private feedback removes the quote and publishable attribution from the prepared message.
- Review is invalidated when answers are edited; messages require visitor action in WhatsApp.
