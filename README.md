# Boaz Hazan — private mathematics lessons

Static Hebrew RTL website published from this repository's root with GitHub Pages.

- index.html: biography, approved recommendations, accurate prices and WhatsApp enquiries.
- materials.html: searchable library of 275 migrated lesson pages, open without registration or access codes.
- materials/: original lesson layouts and interactive exercises, with local links and referenced assets.
- practice.html: three introductory mathematics exercises.
- duckme.html: project background, without outdated commercial offers.
- feedback.html: redirects to Google Forms; responses are stored privately in Boaz's personal Google account, not this repository.

Feedback is never published automatically. Publish only the exact approved quote and attribution after Boaz's approval. Other responses remain private; edited quotations require fresh consent.

The old my-teaching-site repository is preserved unchanged. This site's navigation no longer links to it. School materials include other subjects; private tutoring is mathematics only, excluding 5-unit lessons.

All lessons last 45 minutes. Hadera home visits: elementary 130 ILS, middle/high school 150 ILS. Nationwide Zoom: elementary 100 ILS, middle/high school 120 ILS.

Serve the root with a static HTTP server. No build or dependency installation is needed. Migration checks verified local links, assets and absence of access gates. Browser checks cover catalog filtering and representative exercises. The incomplete numerical-equation exercise generator was completed during migration; this is not a full pedagogical audit of every lesson.

Future expansion should follow Boaz's supplied curricula and existing lesson style. A weekly publishing schedule has not yet been enabled.
